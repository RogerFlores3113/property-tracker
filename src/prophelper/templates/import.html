Good to know

  • Take a backup copy first if you like. The preview shows everything before anything is saved.
  • The file stays in this app's memory for 30 minutes so you can change the column matches. It is never saved to disk and never leaves this computer.
  • A place you already have (same link, or same street address and unit) is not added twice. Only its empty details are filled in, and your notes are never changed.
  • Blank rows, totals rows and rows with spreadsheet formulas are skipped, and the preview says why.
  • Going the other way: download the current search as a spreadsheet (CSV).
